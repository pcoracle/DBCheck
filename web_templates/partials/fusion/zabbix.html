📡 Zabbix 监控设置

配置 Zabbix 服务器地址与凭据，供「系统资源采集」与监控功能复用

🔌 Zabbix 连接配置 未配置
填到站点根即可，系统会自动补 /api_jsonrpc.php；地址与凭据保存在本机 dbc_config.json，凭据加密存储
在 Zabbix 前端「用户 → API 令牌」生成；留空表示沿用已保存值
自签证书环境校验失败时，可临时关闭以避免整段采集不可用
🖥️ 主机取数自查

按主机 IP 或主机名在 Zabbix 中定位主机并读取最新监控项，走的正是巡检时的同一条采集路径——这里能取到，巡检报告里的系统资源章节就能取到。

ℹ️ 使用说明
  • 这里是全局配置：巡检向导第 3 步「系统资源采集」选 Zabbix、以及定时任务的 Zabbix 采集都复用这份地址与凭据，不必逐台重复填写。
  • 系统资源采集的优先级为 Zabbix > SSH > 本机：目标主机已被 Zabbix 纳管时优先取 Zabbix，未纳管或未配置时回落到 SSH。
  • 适合没有 SSH 的 Windows 主机，或已被监控平台纳管、不希望再开采集账号的主机。
